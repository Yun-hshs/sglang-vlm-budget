## 实验设计

复用 32 题先导试验中的模型、短答提示、ChartQA 评分规则与服务端计数。此次固定 **128 道不同图表的题，human 与 augmented 各 64 道**，包含先导试验的全部 32 题。对固定版本的清洗测试集按原图像素面积分层，每个子集从三个层级分别取 55、8、1 道。边界为 602,112 与 1,003,520 像素，前两层包含各自上界。先抽大图，在各层按 `SHA-256(种子:样本ID)` 排序并按图像 SHA-256 去重。较大图表在本样本中的占比高于原测试集。

| 档位 | 客户端配置 |
|---|---|
| 原图 | 保留原图尺寸 |
| 低 | 200,704 像素 |
| 中 | 602,112 像素 |
| 高 | 1,003,520 像素 |
| 自适应 | 使用已有的按问题和图像几何选择高档或低档的规则 |

自适应只读取原始问题及方向校正后的宽高。问题包含 `文字、文档、图表、读取、写、数字、text、read、document、chart、ocr` 中任一片段（英文忽略大小写），或图像高度 > 1,600 且高宽比 > 1.35，选择高档，其余选低档。所有档位使用相同的短答提示，不向规则传入提示后缀、答案或子集标签。固定档与自适应都按所选像素上限保持宽高比，只缩小超阈值图像，再统一编码为 RGB PNG。

RTX 5090 单卡、SGLang 0.5.23、Qwen2.5-VL-7B-Instruct BF16 基座，张量并行为 1，请求并发为 1。Radix Cache、全局多模态缓存和多模态前缀缓存关闭，图像预处理缓存大小为 0。共运行 3 轮，固定种子打乱档位和题目顺序，同一轮的各档使用相同题目顺序。每轮每个固定档预热两条，分别选两个子集中原图面积最大的题。自适应档各用一条低和高的样本预热，取各分支中原图面积最大的题。预热从准确率、视觉 Token 和延迟汇总中排除。

每条请求通过请求 ID 关联服务端 Trace。实际视觉 Token 用网格、空间合并系数、占位符区间和实际占位符数交叉验证。TTFT 从本机发起流式请求计到收到第一段非空正文，图像预处理在计时前完成。评分沿用阶段 1 的 ChartQA relaxed accuracy，数值容许 5% 相对误差，文本忽略大小写并匹配去首尾空白后的短答。保留模型原始预测。 [ChartQA 论文](https://aclanthology.org/2022.findings-acl.177/)

## 复现

按[阶段 2 部署说明](DEPLOYMENT_SMOKE.md)启动固定配置的 SGLang 与追踪钩子。准备阶段 1 已校验的 `data/processed/ablation/test.jsonl` 和相邻 `images/`。可按[阶段 1 数据准备指南](../../phase1-assistant/docs/ABLATION.md)下载并清洗数据。脚本将检查测试导出和所选图像的 SHA-256、服务参数，并保存样本、预热和测量顺序。

```bash
cd 02-Multimodal/phase2-sglang
export PHASE1_DIR="$(cd ../phase1-assistant && pwd)"
# 服务器按独立目录部署时直接设为阶段 1 项目绝对路径。
export PYTHONPATH="$PWD/.runtime:$PWD:$PHASE1_DIR"
out="results/chartqa-128-$(date -u +%Y%m%dT%H%M%SZ)"
python3.12 -m benchmark.chartqa_budget_pilot \
  --dataset "$PHASE1_DIR/data/processed/ablation/test.jsonl" \
  --config configs/chartqa-budget-128.json \
  --trace results/server/vision.jsonl \
  --output "$out"
python3.12 -m analysis.chartqa_budget_pairs \
  --manifest "$out/manifest.json" --requests "$out/requests.jsonl" \
  --output "$out/paired.json"
```
