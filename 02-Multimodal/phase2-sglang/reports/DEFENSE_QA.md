# 常见答辩问题

**为何选 SGLang 而不是重新训练模型？** 课程问题是服务性能与视觉输入需求的关系。使用固定模型隔离输入预算的影响，避免训练因素混入对比。

**你实现的是 Token 剪枝吗？** 当前是客户端图像像素预算控制，没有修改模型内部 Token。实际视觉 Token 必须由图像处理器网格遥测确认。

**自适应策略有什么依据？** 文字读取和文档通常依赖细节，因此用问题词和纵向图像特征选择高预算；这是待验证规则，不是证明成立的最优策略。

**为何没有加速数字？** 当前用户要求不测试，GPU 稍后提供。真实推理未运行，不能把预计值或模拟数据作为研究结果。

**如何公平比较？** 固定模型、精度、数据、解码与版本；随机化组序、预热和三轮重复；按任务分层，同时报告失败率和输出截断。

**客户端 TTFT 是否等于 Prefill？** 不等于，还包括传输、排队与视觉处理。内部阶段需要 profiler 分解。

**是否证明缓存生效？** 没有。Warm 仅表示没有主动清缓存，需实际命中遥测才可论证缓存效果。

**如果预算降低反而变慢？** 应保留该结果并检查图像处理、传输、缓存和排队；不能删掉不符合假设的配置。

**是否可以正式提交课程？** 当前可交付实现与方法初稿。完成 GPU 验证、补真实结果并核对课程评分细则后，才能形成实测终稿。
